# Mohammed Salim — Academic Website

A simple multi-page static website designed for GitHub Pages.

## Files
- `index.html` — Home
- `projects.html` — Projects
- `notes.html` — Research notes
- `publications.html` — Publications
- `talks.html` — Talks and presentations
- `cv.html` — CV
- `styles.css` — Shared styling
- `assets/profile.png` — Profile photograph
- `assets/Mohammed_Salim_CV.docx` — Downloadable CV

## Publish with GitHub Pages
1. Create a new public GitHub repository.
2. Upload **all files and the assets folder**, preserving this exact structure.
3. Open the repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. GitHub will provide the live website URL after deployment.
