# Mohammed Salim — Academic Website

Simple flat-file version for GitHub Pages. All files are in the repository root, so no folders need to be uploaded.

## Files
- `index.html` — Home
- `projects.html` — Projects
- `notes.html` — Notes
- `publications.html` — Publications
- `talks.html` — Talks
- `cv.html` — CV page
- `styles.css` — Shared styling
- `profile.png` — Profile photograph
- `Mohammed_Salim_CV.docx` — Downloadable CV

## Upload to GitHub Pages
1. Create a GitHub repository.
2. Choose **Add file → Upload files**.
3. Select all files from this folder and upload them together.
4. Commit the files.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select `main` and `/ (root)`, then Save.

GitHub Pages will publish `index.html` as the homepage.


## Dark mode
The site includes a light/dark theme button in the header. The selected theme is remembered in the visitor's browser. Keep `theme.js` in the repository root together with `styles.css`.
